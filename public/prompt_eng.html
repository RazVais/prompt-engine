הארכיטקטורה החדשה: MCP ו-Skills

Model Context Protocol (MCP)

תקן פתוח לחיבור Claude למקורות מידע וכלים חיצוניים. במקום לכתוב קוד אינטגרציה לכל API, אנו משתמשים בשרתי MCP מובנים המוגדרים בקובץ .mcp.json.

  • 🔹 הגדרה: הוספה באמצעות claude mcp add.
  • 🔹 דוגמאות: Fetcher, Playwright, Database, Filesystem.
  • 🔹 יעילות: נטען On-Demand כדי לחסוך טוקנים ב-Context Window.

Claude Skills (SKILL.md)

מודולים המעניקים ל-Claude ידע תהליכי (Procedural Knowledge). ממוקמים תחת ~/.claude/skills/ ומאפשרים ל-Claude לבצע משימות ספציפיות באופן עצמאי.

  • 🔸 מבנה: דורש Frontmatter (שם ותיאור) כדי להיטען נכון.
  • 🔸 סגנון כתיבה: ציווי (Imperative) - "עשה X", "בדוק Y", לא "כדאי שתעשה".
  • 🔸 גילוי אוטומטי: Claude מחפש את התיאור וטוען את הכישרון כשהמשתמש מבקש.
🛠️
